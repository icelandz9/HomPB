ใช้ library ตัวเดียวคือ supabase-js 2.45.4 (โหลดจาก CDN) ซึ่งมี 4 ส่วน: Auth (สมัคร / ล็อกอิน) · Database (select / upsert / rpc) · Storage (รูปสินค้า สลิป) · Realtime (แชท) ส่วนที่เหลือเป็น HTML + CSS + JavaScript ล้วน
