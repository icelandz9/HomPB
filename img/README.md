# รูปในเว็บ HomPB

| โฟลเดอร์ | คืออะไร | ใช้ที่ไหน |
|---|---|---|
| `Logo/` | `hompb-icon.svg` โลโก้และไอคอนแท็บเบราว์เซอร์, `hompb-logo-red.jpg` โลโก้สำรอง (ยังไม่ได้ใช้) | หัวเว็บทุกหน้า |
| `rooms/` | รูปห้อง 5 ห้อง: `bed` ห้องนอน, `bath` ห้องน้ำ, `living` ห้องนั่งเล่น, `kitchen` ห้องครัว, `appliance` เครื่องใช้ไฟฟ้า | การ์ด "เลือกซื้อตามห้อง" หน้าแรก, พื้นหลังหน้า login, รูปสำรองของสินค้าที่ไม่มีรูป |
| `products/<ห้อง>/` | รูปสินค้าแยกตามห้อง ชื่อไฟล์ภาษาอังกฤษ เช่น `bed/pillow.jpg` | สินค้าตัวอย่างใน `js/catalog.js` (ชื่อภาษาไทยของแต่ละรูปอยู่ในไฟล์นั้น) และรูปสำรองใน `js/shop.js` |
| `icons/` | `avatar-default.svg` รูปโปรไฟล์เริ่มต้น | หน้าโปรไฟล์ ก่อนผู้ใช้อัปโหลดรูปเอง |
| `icons/dark/`, `icons/light/` | ไอคอน PNG ธีมมืด/สว่าง | `icons/dark/logout-box-r-line.png` ใช้ในหน้าพนักงาน ที่เหลือยังไม่ได้ใช้ |
| `originals/` | รูปต้นฉบับขนาดเต็มของ `rooms/` และสินค้าชุดแรก 9 ชิ้น | ไม่ได้ใช้ในเว็บ เก็บไว้ย่อขนาดใหม่ |

## เพิ่มรูปสินค้า

1. ตั้งชื่อไฟล์เป็นภาษาอังกฤษตัวเล็ก คั่นด้วย `-` (เช่น `rice-cooker.jpg`) แล้ววางใน `products/<ห้อง>/`
2. เพิ่มแถว `["rice-cooker", "หม้อหุงข้าวไฟฟ้า"]` ในห้องนั้นที่ `js/catalog.js`

รูปของสินค้าที่ขายจริงให้อัปโหลดในหน้าคลังสินค้า (เก็บใน Supabase Storage ไม่ได้อยู่ในโฟลเดอร์นี้)
